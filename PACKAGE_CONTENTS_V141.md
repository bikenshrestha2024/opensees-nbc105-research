# Complete V141 bundle

- Root launcher, compatibility modules, complete components and documentation.
- Saved_Project_V141: refined assembled geometry, section/load/support source audits, configuration, story/mass ledgers, source input workbooks, formula workbooks, timing records and refreshed runtime. Start RUN_EXPORTED_PROJECT_GUI.py inside this folder for this saved project.
- Input_Records_V141 and packaged motion catalogue: all 8 available user-provided orthogonal pairs (16 unchanged files), with units/dt/sample inventory. Root and saved-project runtime select these local paths when present.
- Worked examples, recovered history, material cards, mesh benchmark, plots, validation notes and diagnostic viewers.
- Reproducibility_Checks_V141 contains development checks; adjust their workspace/source paths before running elsewhere.

The original ETABS .EDB and installed Python/OpenSeesPy/ETABS are not bundled. The saved OpenSees project runs from its included exported data. Original source paths in provenance and older logs remain historical references. The imported Excel reference files refer to their original source models; they do not certify the revised geometry. Nonlinear material calibration requirements and limitations remain unchanged.
