# V149 visual material and device verification

Run **11_MATERIAL_DEVICE_VALIDATION.py**, or select **Visual validation - Concrete01 / Steel02 / FVD / BRB / walls** in the main GUI validation area. All existing V148 tools are retained. Native tests run in a separate Python process so wipe() cannot destroy the building domain. A timestamped folder preserves each new run. Use the Open saved run folder button for earlier results. This workbench does not change or approve your building materials.

Tabs include parameter cards, response paths, response-versus-step/time graphs, idealization schematics, recorded response playback, GIF export, references and procedures. Four pre-generated GIFs and PNGs are included in Material_Validation_Results_V149. Animation follows the calculated material/device path, not an earthquake deformation of the building. Wall playback traces the patch response only; no missing nodal deformation is fabricated. Schematics are original diagrams, not photographs of tested specimens.

## Numerical cases and parameter provenance

**Concrete01:** unconfined illustrative fpc=-30MPa, epsc0=-0.002, residual=-6MPa, epsU=-0.006. These values are selected demonstration inputs, not extracted from a specimen or your M45 model. Native setStrain commits each coupon step. Compression protocol reaches -0.008 monotonically; cyclic peaks are -0.0005,-0.001,-0.002,-0.004,-0.006 with unloading to zero and final +0.001 tension. Virgin-envelope reference: fc*(2r-r^2),r=epsilon/epsc0, to peak; linear descending segment to residual; constant residual afterwards. Initial E=2fc/epsc0. Observed max envelope discrepancy 3.55e-15MPa and zero tensile stress. This is numerical verification of that law, not validation of tensile cracking, confinement or crushing strain in your project.

**Steel02:** illustrative Fy=355MPa,E=200000MPa,b=0.01. Documented transition choices R0=20,cR1=0.925,cR2=0.15; a1=a3=0,a2=a4=1 explicitly disable isotropic envelope growth. Protocol symmetric peaks 0.0005,0.002,0.005,0.01 strain, ending at zero. Initial modulus check matches 200000MPa. Cyclic curves show the model response; no measured-steel match or fracture/fatigue acceptance is claimed.

**BRB:** same illustrative Steel02 law, uniform yielding core A=0.002m2,Ly=3m. Coupon stress times1000*A gives kN; extension=strain*Ly. A separate native corotTruss displacement-control test in kN-m units agrees with the coupon-converted force within about5.46e-11kN. Fy*A=710kN; EA/Ly=133333.33kN/m are numerical reference values, not selected brace capacities. The whole brace's work-point length, nonyielding end-zone stiffness, compression overstrength, casing, connections and low-cycle fatigue are absent. Steel02 alone is not a BRB qualification test and does not make a conventional brace buckling-restrained.

**FVD:** official nonlinear Maxwell example K=300kN/mm,Cd=280.3kN(s/mm)^0.30,alpha=0.30, amplitudes12/24/36mm at0.5Hz. Converted K=300000kN/m,Cd=280.3*1000^0.30 kN(s/m)^0.30. Run uses two sinusoidal cycles at each amplitude, dt0.002s. Abrupt amplitude transitions produce transients; no experimental curve is inferred. The material is a spring and nonlinear dashpot in SERIES, not the simple F=Cd*v^alpha relation evaluated with total device velocity.

Auxiliary independent linear Maxwell check selects alpha=1,C=5000kN*s/m,K=300000kN/m and u=A*(1-cos(omega*t)), A0.012m,omega=pi rad/s. For a=K/C and F(0)=0:
F(t)=K*A*omega/(a^2+omega^2) * [a*sin(omega*t)-omega*cos(omega*t)+omega*exp(-a*t)].
Native force max discrepancy about5.87e-6kN; refined dt0.001 gives5.90e-6kN. Error is not monotonically reduced: penalty enforcement/algorithm effects remain. Steady-cycle work reference pi*A^2*C*omega*K^2/(K^2+(C*omega)^2)=7.0866866kN*m; numerical7.0866400, relative error6.58e-6. No NBC acceptance threshold is inferred from these errors.

Prescribed displacement uses Penalty1e12 and Newmark0.5/0.25. Native maximum motion-enforcement error is reported (~1.16e-9m for nonlinear example). An uncoupled unit-mass/unit-spring dummy oscillator keeps the system nonempty; it is not part of the damper. Transformation prescribed-motion constraints gave zero device velocity in the tested build, so they are deliberately not used for this verification driver. Review numerical enforcement and step sensitivity before transferring any driver.

**Walls:** E-SFI-MVLEM-3D2023 native PEER2015-material patch and short Lu layered-shell reversal completed; these are not SD-06 reproduction. A separate original SFI-MVLEM-3D2021 patch attempt FAILED at gravity load factor0.7 with solver code-3. The report preserves FAILED, and the workbench shows the status. The original SFI native formulation needs further numerical investigation; it is not called validated. The earlier full Lu cyclic attempt also remains failed. See WALL_VALIDATION_V147.md for geometry, materials, no-boundary-core applicability and all pending physical/mesh/dynamic validation stages.

## Independent reference comparison
Export measured data as step,x,y in exactly the selected case's units and loading order. Select Compare independent measured CSV and supply specimen/citation/unit provenance. The workbench checks finite values, row counts and step identifiers; it then plots the supplied measurement and native response and exports maximum x difference and yRMSE. These conditions do not prove the protocols match. Never sort cyclic points by displacement, interpolate across branches, or treat net open-path work as closed-cycle energy. Acceptance limits, uncertainty and independent validation specimens must be justified separately. No default15% or arbitrary experimental PASS is imposed.
