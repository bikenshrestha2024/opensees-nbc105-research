# V160: sparse eigenanalysis and model inspection
Run 01_START_ETABS_TO_OPENSEES.py from the fully extracted package. Use a short extraction path. In the main GUI select your correct export folder, refresh selected export runtime, then rebuild from saved export before new analyses. Rerun Modal for Both states to replace older caches. PythonSparse is the default solver; scipy and threadpoolctl are required alongside OpenSeesPy 3.8.0 with PythonSparse support.

Changes: sparse shift-invert eigenanalysis shared by Modal, MRSM and time-history damping checks; no automatic dense fallback. Node/frame/area ID categories separate colliding IDs. Batch Stop control, distinct shared-preparation and actual MRSM case stages. Nonlinear dependency inventory and explicit unapproved-draft rebind preserve evidence without approving changed models.

Full-building verification on a workspace copy: 11,097 nodes, 37,650 active equations, 40 modes. ULS gravity 137.2 s plus modal 24.0 s; SLS gravity 180.8 s plus modal 35.3 s. ULS participating mass X/Y 91.27/90.76%; SLS 91.72/93.33%. Solver residuals below 1.7e-7. Runtime depends on hardware and concurrent work. The sparse/native small-model eigenvalues agreed to 3.5e-16 relative error. Nine existing regression tests passed. Full MRSM and earthquake histories were not rerun for this release; the shared eigen stage was tested for both states.

ESM targeted checks: seismic live-load fractions/roof exclusion, ULS/SLS coefficients, period exponent, force distribution, soil spectral boundaries and tall-building diagnostic eligibility. Two-storey hand example gives ULS 40 kN and SLS 32.6667 kN. These checks do not certify the whole building. Tall-building ULS ESM remains a comparison reference where primary-method eligibility fails. Review wall effective stiffness, soil evidence, loads, actual reinforcement and member acceptance separately.

Literature examples and nominal M30/Fe500 cards remain clearly labelled reference assumptions. Rebinding resets approval/checks; it does not establish calibration. No complete building nonlinear design approval is claimed.
