# Individual setup, validation and parameter tuning
Run 14_MATERIAL_PARAMETER_SETUP.py or use Individual material / device setup and tuning in the main section/material review column. Eight independent tabs retain separate cards, runs and output folders. The existing Steel02 experimental calibration and wall validation workbenches remain available.

1. Select the material/component tab. Read source and parameter_basis in its card. Defaults are explicitly ILLUSTRATIVE, not experimentally validated M30/M35/M40/M45 or Fe415/Fe500/Fe550 cards.
2. Edit its JSON parameter card, save it, and set ordered targets and samples_per_leg. Load a saved card to reproduce the setup. protocol_csv optionally supplies ordered x values. Coupon x=strain, y=MPa; BRB/wall x=extension/displacement m, y=kN. Preserve reversal order.
3. Run / tune executes native OpenSees in an isolated process. Each timestamped run retains input.json, response.csv, response.png, Parameter_Study.xlsx, report.json and run.log. Failed runs save failure.json and logs; cyclic wall failure also retains completed samples in partial_wall_response.csv.
4. Animate / GIF plays the recorded response curve; this is material-path playback, not a building deformation animation.
5. Measured CSV must contain x,y, matching units and specimen loading path. Set specimen_id and citation before comparison. Curve overlay and full-history error metrics are exported. No invented acceptance threshold is applied.
6. For Concrete01/02/CM, Steel02/MPF and idealized BRB core, bounded fitting is enabled by fit_bounds, e.g. {"b": [0.001,0.05]}. Starting values must lie strictly inside finite bounds. It fits the first train_fraction of the ordered data, propagating the complete cyclic state through the withheld tail. The tail belongs to the SAME specimen, not independent validation. Sensitivity, parameter identifiability and a different validation specimen still require review. Set fit_bounds={} for manual tuning.

Concrete01: fpc, epsc0, fpcu, epsU; negative compression. Zero tensile strength.
Concrete02: adds unloading ratio, tensile strength and tension-softening slope. Source: https://opensees.github.io/OpenSeesDocumentation/user/manual/material/uniaxialMaterials/Concrete02.html (Yassin 1994).
ConcreteCM: Chang-Mander envelope/shape and critical strains, Ec, tension parameters. Source: https://openseespydoc.readthedocs.io/en/latest/src/ConcreteCM.html (Chang and Mander 1994; Kolozvari et al. 2015). Coupon uses full hysteretic response; FSAM uses its own material interaction.
Steel02: Giuffre-Menegotto-Pinto with isotropic hardening. Existing qfem-0019 published data fit remains separate from illustrative starting values. https://nheri-simcenter.github.io/quoFEM-Documentation/common/user_manual/examples/desktop/qfem-0019/README.html
SteelMPF: separate positive/negative strengths and hardening; R0,cR1,cR2 and isotropic terms. https://openseespydoc.readthedocs.io/en/latest/src/SteelMPF.html
FVD: manual K,Cd,alpha and dt study using the existing native Maxwell transient driver. The current protocol is the documented example: 12/24/36 mm sinusoidal amplitudes, 0.5 Hz, 4 seconds per segment. Custom experimental displacement-time alignment and optimizer are not implemented in this panel; selecting measured data produces an explicit error. K=300 kN/mm becomes 300000 kN/m; Cd=280.3 in mm basis becomes 280.3*1000^0.3 in m basis. https://opensees.berkeley.edu/wiki/index.php?title=ViscousDamper_Material ; Akcelyan, Lignos and Hikino (2018), Soil Dynamics and Earthquake Engineering 113,488-502.
BRB: manual/fit study of a uniform Steel02 yielding core; extension/length gives strain, stress*1000*area gives kN. This panel does not simulate casing instability, fatigue, connections, effective nonyielding zones or qualification tests. Black, Makris and Aiken, PEER2002/08: https://peer.berkeley.edu/publications/2002-08
SFI_MVLEM_3D: manual panel geometry/fiber count, axial force, reinforcement ratios, SteelMPF, ConcreteCM and FSAM study. wall_formulation selects ORIGINAL SFI_MVLEM_3D or E_SFI_MVLEM_3D; these are distinct formulations. Base fixed, top UX tied, out-of-plane/torsion restrained. It is a planar numerical patch, not the project core or SD-06 specimen. Original SFI default cyclic example fails at step78 and is reported FAILED; E-SFI default example completes. No solver failure is silently relabelled validation. References: https://kkolozvari.github.io/SFI-MVLEM-3D/ ; https://kkolozvari.github.io/E-SFI-MVLEM-3D/ ; https://doi.org/10.1016/j.engstruct.2023.116700 . Use the existing wall validation workbench for the broader mesh/biaxial/experiment plan.

All Excel coupon stress conversions use MPa*1000=kN/m2. Project assignments, material approval and NBC building design checks are not altered by these isolated studies. No wall experimental validation is claimed.
